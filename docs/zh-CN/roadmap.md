# 路线图

## v0.1：基线产品

Core/Schema、Existing Asset、Image/Video Draft、Doctor、MuJoCo/Three.js Compiler、本地 CAS 与 L0–L3 报告。当前仓库已完成文档/Schema 基线和首个 Rust Validator。

## 后续候选

1. **Profile 扩展**：Isaac Sim/PhysX、Genesis、SDF/Gazebo、Drake。
2. **Registry**：OCI 分发、签名、依赖解析、企业权限与语义 Diff/Merge。
3. **Marketplace**：许可、结算、版本、质量评级和供应商治理。
4. **World Generation**：程序化布局、资产组合、约束求解和多样性审计。
5. **Task/Benchmark**：TaskSpec、Episode、Predicate Monitor、可解性证书和跨后端评测。
6. **复杂物理**：软体、布料、液体、颗粒和动态拓扑事件。
7. **真实校准**：主动采集、系统辨识与 Sim2Real 行为校准。

进入下一阶段的门槛是 v0.1 实测证明目标加载率、人工成本、行为偏差和资产权利流程可接受，而不是按日期自动扩张。
