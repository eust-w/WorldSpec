# ADR-0008：许可与贡献

## 决策

Open Core 采用 AGPL-3.0 与商业许可双轨。外部贡献通过 CLA 授予项目方再许可所需权利。

## 后果

正式法律文本必须由法务完成；在此之前不能把仓库说明当成完整许可。第三方代码、模型、权重、数据和资产分别建立 RightsSpec/Notices，未知权利阻止商业发布。
