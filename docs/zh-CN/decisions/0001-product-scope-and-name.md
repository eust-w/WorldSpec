# ADR-0001：产品范围与工作名

## 决策

产品定位为具身资产平台。v0.1 同时覆盖规范编译器、Existing Asset → SimReady、Image/Video → AssetDraft 三条闭环，并作为一个整体版本验收。

`WorldSpec` 作为工作名，公开品牌另行决定。`SimForge` 因已有 [Physical AI 产品](https://simforge.io/)、[AI 产品](https://simforge.ai/)和[同名开源框架](https://andrejorsula.github.io/simforge/)而不采用。

## 后果

三条闭环必须共享 Core、Evidence、Compiler、Reports 和认证规则。品牌未定不阻塞内部 Schema `$id`，但公开发布前必须完成商标检索和命名迁移方案。
