# ADR-0021：H1 A5 首次行为失败后的处理

## 已确认事实

2026-07-29，A5 在一张 NVIDIA A800-SXM4-80GB 上完成了第一次真实任务运行。
运行使用锁定的 Motion、Capture、Stand Checkpoint 和镜像
`sha256:f3eaaa71...89f0d8`。结果为 `formalTaskGate=failed`，其余四次没有执行，
也没有启动 100M。

失败证据表明：

- H1 完成 1.3973 米前进，最低基座高度为 0.9883 米，最低直立余弦为 0.9941；
  没有提前终止、NaN、关节越限或异常接触；
- 任务停在 `reach_handle`，100 步后目标误差仍约 0.3926 米；
- 杯子在机器人到达前从初始高度 1.1928 米跌到地面约 0.0349 米，说明两条侧轨
  没有形成有效支撑面；
- MJX 日志出现 1069 次 broadphase capacity overflow，实际提示至少需要
  `nconmax/naconmax=19`，而当前单环境容量为 16。

规范化失败报告见
[`kitchen-task.a800.failed.json`](../../../examples/h1-kitchen/kitchen-task.a800.failed.json)，
完整内部 Trace Digest 为
`sha256:20d065ef...fc506f`。

## 决策

用户于 2026-07-30 选择 **A5-R**。本轮只修复已经证实的基准和控制器实现缺陷，
不引入底座微调、MPC/QP、隐藏抓取约束或自动调参重试。A5-C 和 A5-S 不再作为
当前实施路径。

### A5-R：先修复基准，再验证控制

- A5 专用接触容量提升到至少 32；
- 用真实碰撞支撑面替换无效侧轨，但不增加 weld、mocap 或隐藏附件；
- 在启动 A800 前增加固定基座 IK 可达性扫描，并把柜体相对位置约束到明确的
  可达余量；
- 保持 A4 三策略、四关节右臂控制器和物理抓取边界不变；
- 重新运行一次门控，只有通过才继续 5/5。

这条路线先消除已证实的无效基准条件，最容易区分“控制器能力不足”和“场景本身
不可执行”。

### A5-C：同时升级操作控制器

在 A5-R 的修复基础上，允许站稳后的底座微调或任务空间 MPC/QP，使基座和右臂
共同满足把手与杯子的可达性。它更接近真实全身操作，但会扩大 A5 控制边界，验证
成本和安全审计范围更大。

### A5-S：只保存失败证据并停止

不再消耗 A800 资源。A5 保持 `non_publishable`，后续等真实厨房几何、经验证的
安装位姿或更完整操作策略到位后再恢复。

不建议只增加超时时间或直接开始任务训练：当前杯子支撑和接触容量已明确无效，
这样做会把基准缺陷混入策略。

## A5-R 实施收敛

A5-R 固定以下变化：

- 单环境 MJX 容量固定为 `active=32`、`ccd=16`、`njmax=128`；
- 以尺寸为 `0.10 × 0.09 × 0.015 m` 的固定碰撞盒替换两条无效侧轨；
- 右臂仍只控制四个既有 H1 关节，但每个控制周期以最多 96 次 DLS 迭代求完整
  关节目标，不再只发送一次 `0.04 rad` 增量；
- 每次进入操作阶段前，必须从实际站稳状态扫描 10 个固定任务空间目标；最大残差
  不得超过 `0.015 m`，最小关节限位余量不得低于 `0.05 rad`；
- 预检失败立即返回 `ik_reachability_preflight_failed`，不得消耗后续五次运行。

2026-07-30 在真实组合后的 H1 + Robotiq 模型上完成 MuJoCo 3.6.0 CPU 预检：

- 10/10 目标通过；
- 最大 IK 残差 `0.007970 m`；
- 最小关节限位余量 `0.331436 rad`；
- 杯子在新支撑面上步进 1,000 步，最低高度 `1.193790 m`，结束高度
  `1.193808 m`；
- 该 CPU 证据只证明固定基座运动学可达和杯托物理有效，不证明 MJX/A800 动态
  操作成功。

结构化证据见
[`kitchen-task-preflight.darwin-arm64.passed.json`](../../../examples/h1-kitchen/kitchen-task-preflight.darwin-arm64.passed.json)。

下一项放行证据仍必须来自锁定新镜像的 A800 单次门控。只有单次通过才自动继续
其余四次；任何行为失败都停止，不启动 100M。
