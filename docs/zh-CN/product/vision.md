# 产品愿景

## 定位

WorldSpec 是具身资产平台，不只是新文件格式。它提供规范语义模型、资产锻造流程、跨后端编译、诊断和证据化认证。

核心价值是：

1. 让已有 Mesh、CAD、机器人描述和重建结果进入统一、可追溯的资产草稿。
2. 将视觉、碰撞、质量、语义几何和原生载荷分开建模。
3. 针对目标 Profile 做显式转换，并报告所有近似、烘焙、模拟、删除和不支持项。
4. 用真实加载和行为测试把“生成成功”升级为有证据的认证结论。

## 目标用户

- 需要批量把 3D 资产变成 MuJoCo/网页预览资产的机器人团队。
- 需要可审计物理和碰撞数据的仿真工程师。
- 需要从图像或视频生成资产草稿的 Real2Sim 团队。
- 需要发布可追溯资产包的资产供应方。

## 非目标

- 描述现实世界的全部现象。
- 声称不同物理引擎逐帧等价。
- 用单图自动恢复真实质量、摩擦和隐藏结构。
- 在 v0.1 建设 Marketplace、OCI Registry、正式 Web 工作台或完整 Task/Benchmark 平台。

公开品牌尚未确定；`WorldSpec` 只是工作名。公开发布前必须完成品牌与商标检索。
