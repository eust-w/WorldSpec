# ADR-0001: Product scope and working name

The Chinese document is the normative source; this page is its official translation.

## Decision

The product is an embodied-asset platform. v0.1 jointly covers the canonical compiler, Existing Asset → SimReady, and Image/Video → AssetDraft as one release.

`WorldSpec` is the working name. The public brand is separate. `SimForge` is rejected because it is already used by a [Physical AI product](https://simforge.io/), an [AI product](https://simforge.ai/), and an [open-source framework](https://andrejorsula.github.io/simforge/).

## Consequences

All three loops share Core, Evidence, Compiler, Reports, and certification rules. The pending brand does not block internal schema `$id`, but public release requires trademark search and a naming migration plan.
